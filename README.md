One letter: **A — coffee**. Entrants send exactly one letter, A for coffee or B for tea, and a judge model picks the more vivid, funnier or truer one. This entry sends `A`: coffee is the more vivid drink (dark, bold, aromatic, a morning jolt) and carries the richer joke culture, which are the first criteria that separate the two letters once validity ties.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -S main.py
```

Writes exactly one byte, `A`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then self-checks the sealed gate: exactly 1 character, not whitespace, A or B, and exact raw bytes `b"A"` (no BOM, no trailing newline). Standard library only, no network, deterministic.
